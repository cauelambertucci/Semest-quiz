# Texto para currículo e LinkedIn

## Título
SEMEST Quiz — plataforma de quiz multiplayer

## Descrição curta
Criação de uma plataforma de quiz para a Semana da Estatística da Unicamp, com apoio de IA na implementação. Definição de requisitos e personalização de salas por código, perguntas cronometradas, ranking, editor com salvamento persistente e avatares. Projeto em TypeScript e React, com Cloudflare Workers e banco D1/SQLite.

## Como apresentar
1. Crie um repositório no GitHub e envie o conteúdo desta pasta, incluindo o README e os arquivos de configuração necessários.
2. Não envie `.env`, `.dev.vars`, tokens, senhas, banco real ou informações dos participantes.
3. No currículo, inclua o título, a descrição curta, o link do repositório e a demonstração.
4. No LinkedIn, adicione o link da demonstração ou do GitHub à seção de projetos ou destaques.
5. Cite somente tecnologias e decisões que você consegue explicar; informe o apoio de IA na implementação.

Demonstração: https://semest-quiz.caue-lam.chatgpt.site
